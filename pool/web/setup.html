# How to mine WAM Coin

Disclaimer: All downloads are provided by the official WAM Coin github repository.

1. Download the files

Download wamd + wam-cli: macOS wam-coin
Download wam-miner: macOS wam-miner

Step 1 — Run the WAM Daemon
(Keep it running for all wallet operations, not required for mining)

./wamd -daemon

Step 2 — Create a WAM Wallet and note down the address

The address will look something like this: wam1q0dkfqdkx8qgwsxlyl7g54383p64js5ywk5jcly

./wam-cli createwallet "A-NAME-FOR-YOUR-WAM-WALLET"

Step 3 — Start mining with 2 cores
(you can change the core-count value passed to parameter -t at the end of the command) 

./wam-miner -o stratum+tcp://wampool.vslabs.co.in:3333 -u YOUR_W_ADDRESS --large-pages -t 2
